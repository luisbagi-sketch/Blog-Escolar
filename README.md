# Blog-Escolar

Equipe:
  Luis Gustavo Guisone Bagi
  Larissa Prado Araldo

Tema e problema:
  Nosso tema é voltado para a transmissão de noticias estudantis, como um portal/blog que irá disseminar eventos escolares, palestras ou até mesmo sábados letivos. Focando em resolver o problema da distribuição trabalhosa de novidades (diversos grupos para toda a escola, redes sociais etc.). Tendo o portal escolar as noticias serão centralizadas nele, assim todos os estudantes terão acesso direto, podendo até líderes de sala publicar ocasionalmente algo. 

Requisitos funcionais:
  O sistema deve permitir o login de usuários;
  O sistema deve diferenciar os perfis de aluno, aluno representante e professor;
  O aluno representante deve poder publicar notícias;
  O aluno representante e o professor devem poder editar notícias;
  Todos os usuários devem poder visualizar a lista de notícias;
  Todos os usuários devem poder abrir e ler uma notícia completa;
  O sistema deve exibir a data de publicação e o autor de cada notícia.

Requisitos não funcionais:
  O site deve ser responsivo, funcionando em computadores e celulares;
  Apenas usuários autenticados com o perfil adequado podem publicar ou editar notícias;
  As senhas devem ser armazenadas de forma criptografada;
  A interface deve ser simples e de fácil uso;
  O sistema deve manter os dados em um banco de dados;
  O código deve ser versionado no GitHub.
